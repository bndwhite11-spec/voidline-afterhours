VOIDLINE / RELIABILITY INVARIANTS

1. A success state requires a committed write.
Cause: send cleared composer/attachments before persist and ignored false.
Contract: mutation returns committed state only after an atomic journal write;
failed changes roll back visible domain state and retain form input plus a
retryable field patch. Recovery export includes pending patches and legacy
snapshot. No success announcement follows failed persistence.
Regressions: voidline-reliability-test; voidline-mutation-failure-test;
voidline-profiles-audit-test; voidline-badges-audit-test.

2. Retained children require accessible parent context.
Cause: slicing histories at 500 removed roots but kept replies.
Contract: no destructive history slicing. Render pages of100 and preserve IDs,
quotes, pins and all replies. Older already-orphaned histories receive explicit
system recovery context; no missing user words or author are invented.
Regressions: voidline-reliability-test; voidline-journal-test.

3. Independent concurrent edits must survive.
Cause: message-only merge followed by whole-snapshot overwrite erased newly
created navigation entities. Persistence now lives in dist/store.js.
Contract: each tab writes a unique, immutable operation key in one atomic
localStorage.setItem. Changes compare against that tab's committed baseline,
so stale unchanged fields are not writes. Entities/channels are keyed by ID;
conflicting fields resolve by Lamport clock and operation ID. Tombstones win
against message resurrection. Media lives in the operation that changed it,
not a complete checkpoint serialized to storage on every interaction.
Regressions: voidline-journal-test; voidline-reliability-test.
Limit: localStorage quota still applies. Journal replay scans local operations;
there is no claimed IndexedDB/blob-storage migration or infinite capacity.

4. Imports must survive reload without hidden capacity truncation.
Cause: an import accepted25 communities; normalization kept only24.
Contract: build a candidate, validate limits/references/media/version, preview
conflict policy, then commit. Normalization never silently truncates accepted
history or navigation entities. Concurrent accepted records remain reachable.
Regressions: voidline-reliability-test; voidline-regressions-test.

5. A visual update must preserve unrelated interaction.
Cause: innerHTML rebuilt the thread form after background changes.
Contract: keep composer/form identity for the same thread. Reconcile keyed
message rows and targeted parts; preserve media elements when their sources
do not change. Keep reading positions/anchors and caret; mark only reached
content read. Index reply counts once per channel render.
Regressions: voidline-reliability-test (node/text/caret/focus); exact reply jump.
Browser media playback/scroll geometry still require actual browser QA.

6. Search ordering precedes pagination.
Cause: bucket-order slicing omitted the globally newest match.
Contract: filter then globally sort by time/ID, then limit. Navigation loads
and focuses the exact result even in an older thread page. Escaped matching
snippets never interpret user text as markup.
Regressions: voidline-reliability-test; existing formatting tests.

7. Displayed requirements must agree with executable eligibility.
404 Angel uses the profile completion predicate: identity text AND a meaningful
appearance difference from defaults or valid uploaded avatar. Edition provenance
is separate from achievement progression. Sample collections are read-only and
scoped to the selected sample identity. Client accent uses readable presets;
profile colors are not global reading preferences.
Regressions: profile/badge audit tests and real module contracts.

8. One motion policy owns every entrance path.
dist/motion.js considers OS reduced motion and the committed journal setting.
Replay consults that policy before creating DOM. Entrance makes background
controls inert, blocks competing shortcuts, completes from real animation
completion events with a bounded fallback, and restores focus on skip/cancel.
Regressions: voidline-motion-test (simulated completion events).

TRUST EDITION / SIX CONFIRMED INTERACTION DEFECTS

9. A tab owns its active destination.
Cause: shared archive snapshots contained server/channel/reading position and
replaceState adopted another tab's selection under the current unsent text.
Fix: ignore those fields in new shared-journal operations. Preserve current
location while adopting shared data; use drafts.js sessionStorage for tab UI.
Legacy location fields remain read-only migration hints, not broadcasts.
Regression: voidline-trust-test, foreign-tab navigation with an unsent draft.

10. Draft text, reply target and attachments survive same-tab refresh.
Cause: main/thread maps existed only in memory.
Fix: per-tab session storage holds drafts by conversation and thread root,
plus active location/reading positions. Attachment bytes are immutable session
records; typing rewrites small text metadata, not every image/audio byte.
Only garbage-collect unreferenced media after metadata commits. Failed session
writes keep memory, show persistent recovery actions and warn on leaving.
Recovery JSON restores drafts through preview; conflicting current drafts win
unless the user explicitly chooses replacement. Browser tab close ends this
session unless the browser itself restores it; this is not cross-device sync.
Regressions: trust refresh/reply/thread/image/audio/session-quota cases.

11. Read state follows visibility, not a required scroll gesture.
Cause: scroll/jump handlers were the only triggers; short channels cannot scroll.
Fix: schedule viewport read checks after opening/restoring a channel, foreign
content updates, resize/visibility changes, dialog close and entrance finish.
Skip obscured/hidden views and preserve keyboard focus when unread counts
refresh navigation. Update community indicators with channel indicators.
Regression: fully visible short-channel trust case, no synthetic scroll.

12. The primary search fulfills its invitation.
Cause: command palette searched commands/channels but promised people too.
Fix: grouped People, Channels, Messages and Commands results with meaningful
actions and listbox semantics. The advanced message search retains filters.
Regression: nova is a usable person result in the primary command interface.

13. Absence and intentional emptiness are different states.
Cause: ensureContext created an empty active bucket before seed tested absence.
Fix: seed before materializing the active empty bucket. Existing empty arrays
and all previous user records remain untouched. New sample work rooms can be
introduced without replacing older conversations.
Regression: pristine general is populated; intentionally emptied general stays
empty; prior work/messages survive new community content.

14. Keyed static nodes also need an update path.
Cause: reconciliation reused 'intro' while only patching message sub-elements.
Fix: reconcile static-node children as complete static content, retaining the
specialized stable message/media path for actual messages.
Regression: trust-reconcile-fixture exercises the real template branch; a keyed
introduction changes its contents without duplication. This does not pretend
to be a browser visual test.

SHARED TEXT / BUILD INVARIANTS

15. Local archive data and shared room records have separate ownership.
Local messages, contacts, artifacts, sample personas and local attachments are
not silently uploaded when a visitor enters Shared rooms. The shared API uses
platform identity and membership for every community/channel data operation.
Public aliases are display data; platform IDs are the authorization keys.
Sign-in email and account names are not published as a member's social alias.

16. Shared send success follows a durable acknowledgment.
A stable clientId identifies one intended send across retries. The database
uniqueness constraint prevents duplicates after a lost response. Reusing an ID
for different text fails. History/catch-up uses the committed sequence cursor,
not client wall-clock order. A saved state does not imply delivery/read receipts.

17. Schema ownership belongs to generated migrations.
db/schema.ts extends the six-table v6 contract with additive migrations. Run npm run
db:generate after schema edits. Review and retain the generated SQL, journal
and snapshot. Applied migration history is immutable. Request handlers perform
bounded data operations and never create or alter migration-owned tables.
Sites provisions the declared DB binding and applies hosted migrations.

18. Generated output must not become source input.
Authored client assets remain in dist/. build_offline.py inlines linked local
styles/scripts, marks data-offline=true, and includes polish/live modules.
The offline shared-room interface reports unavailable and does not call the
shared API. The local archive remains usable with all its bundled assets.

The source ZIP includes authored client/Worker source, tests, package inputs,
build scripts, db/schema.ts and generated migration history. It excludes the
ZIP itself, dist/server, dist/.openai, node_modules, runtime state and local
secret files. scripts/build-worker.mjs separately excludes server/.openai from
its asset map. Always regenerate downloads before the final Worker build.

SHARED CONVERSATIONS / UPGRADE INVARIANTS

19. Changes are durable events, not only new message sequence numbers.
Mutations and their change records commit together. Reconnection replays edits,
deletions, reactions and pins from the last applied cursor. Deletion blanks
content while retaining IDs for references. A retry validates the original
request fingerprint, so editing a confirmed message cannot create a duplicate.

20. Account tools never inherit another identity's state.
Shared favorites, bookmarks and read watermarks are private account records.
Every mutation must contain the expected authenticated account ID. Both client
identity epochs and navigation/request generations reject stale responses.
Search query ordering is independent from dialog and account ordering.

21. Permissions are reevaluated for every source access.
A saved message is not a permanent grant to private conversation content.
Leaving/removal revokes history, search, source jumps and bookmark previews.
References remain opaque and removable when the original is unavailable.

22. Client, download and deployed Worker must agree.
scripts/check-build.mjs imports the actual generated Worker and compares every
served asset with the source bytes, checks HEAD/ETag and hidden build paths,
and checks packaged migrations and the preserved Site identity. The isolated
delivery suite injects secret/dependency/recursive-output canaries and verifies
they cannot enter the source ZIP. These are not browser screenshot tests.
