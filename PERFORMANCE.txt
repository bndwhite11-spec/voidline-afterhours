VOIDLINE / VALIDATION AND PERFORMANCE SCOPE

Current source extracts ordered native outbox, realtime, measured Standard
history window, media validation/cropping and collectible art into coherent
modules. Matrix/Rust cryptography remains locally hosted and lazy-loaded.

Measured-window controlled tests use 10,000 variable-height rows, bounded mounted
nodes, cached detached rows and anchored scroll updates. Focus/selection pins
and stable media nodes are checked with controlled DOM interfaces. These are
structural/behavior tests, not browser frame rate, layout, typing latency or
physical-phone measurements.

The deployable Worker check compares every allowed asset's original bytes,
HEAD and ETag semantics, direct entry routes, API guards, strict CSP and excluded
private paths. Source bytes, compressed Worker size and hosted transfer checks
are recorded in the release report. The Sites proxy owns HTTP compression.

Real browser parsing/painting, input latency, scrolling memory, audio continuity,
software keyboard, real crop decoding,200% zoom and device/network benchmarks
remain unverified. Do not translate Node/VM timings or a local workerd request
into a mobile performance or product-wide security claim.

Historical archive-only microbenchmarks live in prior Git history. Their local
journal timings do not describe the current shared messenger's performance.
