Method
Read the shipped CSS and evaluate the shipped theme.js palette generator in JSDOM. Independently calculate WCAG sRGB relative luminance using the 0.04045 breakpoint and the (L1+0.05)/(L2+0.05) ratio. The custom light example uses background #fafafa and accent #712a7a. High contrast is the shipped override over Graphite. All figures below are contrast ratios to 1. Source mapping
dist/home.css supplies shell tokens, high-contrast overrides, timeline body, timestamps, selected navigation, incoming/outgoing backgrounds and the general 2px focus outline with 3px offset. dist/appearance.css supplies the resolved primary button colors; theme.js supplies custom palettes. dist/profiles-panel.css supplies studio tab, status, bio, look tile and focused/reordering selectors. The two new studio controls use a 2px outline with 2px offset. The selected look also exposes aria-pressed and a check mark.

Keyboard and targets
Badge earlier/later use native buttons with 44px minimum width and height and restore focus after a move. Section reset has a 44px minimum height. Base primary/secondary actions are at least 44px high. Coarse-pointer message actions and reaction buttons declare 44px minima; fine-pointer hover actions may use 32px. Studio section tabs declare 40px height and preview tabs 36px on desktop; below or at 760px section tabs and pane-switcher buttons become 44px, preview tabs 40px. These are CSS minima, not target dimensions measured on a device.

Responsive source checks
320px and 390px activate the single-column messenger shell and single-pane studio; small phones wrap badge move controls under each slot (520px rule). The 320px view additionally uses the narrower-than-380px studio controls. 768px uses the single-column messenger shell; the studio changes to its two-pane grid above 760px. 1440px uses the desktop shell and the studio width is capped at 1160px. Under 860px the layout accounts for safe-area insets and the reported visual viewport for keyboard changes.

Scope
Static CSS/palette and fixture evidence. Pixel rendering, focus traversal by assistive technology, clipping with zoom or a virtual keyboard, arbitrary user-uploaded imagery, every custom palette or composite overlay and physical Android/iOS/PC behavior were outside this measurement. Forced-colors delegates the resulting palette to the system.
