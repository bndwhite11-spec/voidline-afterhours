VOIDLINE
Your people. Your frequency.

START
Open dist/downloads/voidline-offline.html in a modern browser.
This is the complete standalone app. It works without an internet connection.
You can also open dist/index.html to use the source version.

FEATURES
Three sample communities, separate text channels, local custom servers,
message search, image attachments, reactions, editable profiles, and badges.
Choose LARP Pro Max, Founding Ghost, or Night Creature. No subscription.

Messages, profile, and badges save in this browser on this device.
History is limited to 100 messages per channel. Image attachments are limited
to 2 MB each and available browser storage. Clearing browser data clears
your history. Drafts last for the current session. New copies start fresh.

SCOPE
The built-in conversations and community members are demo content.
This edition has no messaging server, account system, or live voice calls.
The network card uses documentation-only sample data. It collects no IPs,
requests no geolocation, and makes no external IP lookup requests.
On the hosted edition, ordinary hosting/authentication traffic still occurs.

EDIT AND BUILD
Edit dist/index.html, dist/styles.css, or dist/app.js.
Run: python3 build_offline.py
This regenerates the single-file app and the complete source ZIP.
No JavaScript packages or build dependencies are required.

KEYBOARD
Enter: send. Shift + Enter: new line. Ctrl/Cmd + K: search.
Escape: close dialogs or mobile navigation.

VOIDLINE is an independent chat interface prototype.
